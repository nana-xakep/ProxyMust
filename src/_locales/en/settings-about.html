ProxyMust

ProxyMust is a fork of the SmartProxy extension. We respect and thank the original author Salar Khalilzadeh for his excellent work. The original SmartProxy can be found at https://github.com/salarcode/SmartProxy.

Using proxies couldn't be easier with ProxyMust. Think of it as a "configure once and forget" solution. With ProxyMust, you don't need to manually change your proxy settings or turn them on and off. Just tell ProxyMust to enable the proxy for the website you need with one click. After that, whenever you visit that website, ProxyMust will automatically route all your data through the proxy – without any additional action on your part.

ProxyMust offers many features for both beginners and advanced users, including:

  • Enabling the proxy for a specific site on a tab – everything opened in that tab automatically uses the proxy. This feature is called "proxy per tab".
  • Automatically detecting whether to enable or disable the proxy for certain sites based on rules.
  • Quickly switching between multiple proxy servers as the active proxy.
  • Enabling the proxy for the current site with a single click.
  • Viewing resources and requests of the current site, and enabling the proxy for them with one click.
  • Easy switching between proxy modes or enabling the proxy for all domains.
  • Backup and restore of settings and rules.

Please note:

ProxyMust does not provide any proxy servers.
ProxyMust does not track you in any way.
ProxyMust is ad‑free and does not interfere with web page content.

New ProxyMust features

📊 Rating and status system

  • For each proxy and each tested site, the status is shown:
    • ✅ – definitely works for this site (fresh success)
    • ☑️ – likely works (success was earlier or obtained for another site)
    • ❓ – no data (proxy not tested for this site)
    • ⛔ – does not work (fresh failure)
  • Each proxy's rating automatically changes based on test results: +1 on success, -1 on failure.
  • You can also manually change the rating via the context menu (right‑click on a proxy row in the table or on the active proxy in the toolbar popup).
  • Statuses are considered "fresh" for a configurable number of hours (default 6). If data is stale, an indirect status (☑️) is used.

📋 Managing the proxy list

  • Context menu in the proxy table (right‑click) – quickly change rating, priority (pin, star), export selected, copy addresses, delete, clear statuses and ratings, run tests for selected proxies.
  • Sorting in the toolbar popup – by rating and priority (📌 pinned at the top, ⭐ favourites).
  • Sorting in the settings table – by country, protocol, rating.

🚀 Proxy testing

  • Cycle test – sequentially switches the active profile and proxy, checking site loading. Reliable but slow.
  • Express cycle test – accelerated testing that stops at the first success. Good for quick assessment.
  • Precise (slow) test – more thorough, takes longer, gives more reliable results (does not work in Firefox).
  • Express test – fast but may miss some working proxies. Good for a quick overview (does not work in Firefox).
  • Quick tests from the toolbar popup – test the current site for all proxies or only for subscription proxies.

⚠️ Important for users: During tests, the active profile and proxy are actually switched. This may interfere with normal browsing. Run tests when the browser is not being used for other activities.
