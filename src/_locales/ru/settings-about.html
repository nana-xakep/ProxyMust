ProxyMust

ProxyMust является форком расширения SmartProxy. Мы с уважением и благодарностью относимся к автору оригинала Salar Khalilzadeh за его отличную работу. Оригинальный SmartProxy можно найти на https://github.com/salarcode/SmartProxy.

ProxyMust даёт вам полный контроль над прокси-соединениями. Вы самостоятельно добавляете свои прокси-серверы (ручные или из подписок), а встроенная система автоматического тестирования проверяет их работоспособность для каждого сайта, отбирает лучшие и сортирует по рейтингу, приоритету и свежести результатов. Благодаря этим настройкам вы можете доверить ProxyMust автоматическое переключение прокси для сайтов, которые не открываются без прокси – режим Автопрокси сам найдёт рабочий прокси и соединит вас с нужным сайтом, без лишних действий с вашей стороны.

ProxyMust предлагает множество функций как для начинающих, так и для опытных пользователей, включая:

  • Включение прокси для отдельного сайта на вкладке – всё, что открыто на этой вкладке, автоматически использует прокси. Эта функция называется «прокси на вкладку».
  • Автоматическое определение необходимости включения или отключения прокси для определённых сайтов на основе правил.
  • Быстрое переключение между несколькими прокси-серверами в качестве активного.
  • Включение прокси для текущего сайта одним щелчком мыши.
  • Просмотр ресурсов и запросов текущего сайта, возможность включить прокси для них одним щелчком.
  • Простое переключение между режимами прокси или включение прокси для всех доменов.
  • Резервное копирование и восстановление настроек и правил.

Обратите внимание:

ProxyMust не предоставляет никаких прокси-серверов.
ProxyMust никак вас не отслеживает.
ProxyMust не содержит рекламы и не вмешивается в содержимое веб-страниц.

Новые возможности ProxyMust

📊 Система рейтингов и статусов

  • Для каждого прокси и каждого проверенного сайта отображается статус:
    • ✅ – точно работает для этого сайта (свежий успех)
    • ☑️ – вероятно работает (успех был ранее или получен для другого сайта)
    • ❓ – нет данных (прокси не тестировался для этого сайта)
    • ⛔ – не работает (свежий провал)
  • Рейтинг каждого прокси автоматически изменяется по результатам тестов: +1 при успехе, -1 при неудаче.
  • Вы также можете вручную менять рейтинг через контекстное меню (правый клик по строке прокси в таблице или в панели инструментов на активном прокси).
  • Статусы считаются «свежими» в течение заданного количества часов (по умолчанию 6). Если данные устарели, используется косвенный статус (☑️).

📋 Управление списком прокси

  • Контекстное меню в таблице прокси (правый клик) – быстрое изменение рейтинга, приоритета (закрепление, избранное), экспорт выбранных, копирование адресов, удаление, очистка статусов и рейтингов, запуск тестов для выбранных прокси.
  • Сортировка в панели инструментов – по рейтингу и приоритету (📌 закреплённые сверху, ⭐ избранные).
  • Сортировка в таблице настроек – по стране, протоколу, рейтингу.

🚀 Тестирование прокси

  • Циклический тест – последовательное переключение активного профиля и прокси с проверкой загрузки сайта. Надёжный, но медленный
  • Экспресс-циклический тест – ускоренное тестирование с остановкой при любом успехе. Подходит для предварительной оценки.
  • Точный (медленный) тест – более тщательная проверка, занимает больше времени, но даёт более достоверный результат (не работает в Firefox).
  • Экспресс-тест – быстрая проверка, но может пропустить некоторые рабочие прокси. Подходит для предварительной оценки (не работает в Firefox).
  • Быстрые тесты из панели инструментов – проверка текущего сайта для всех прокси или только для подписочных прокси.

🤖 Режим Автопрокси

  • Для сайтов, которые не открываются напрямую (например, из-за региональных ограничений), Автопрокси автоматически создаёт правило в выборочном профиле и подбирает рабочий прокси.
  • При первом посещении такого сайта появляется диалог с предложением добавить его в автопрокси. Вы соглашаетесь – и система сразу находит лучший прокси на основе рейтинга, статусов и приоритета.
  • После успешной загрузки страницы вы можете закрепить найденный прокси для этого сайта (временно, до закрытия браузера) или продолжить поиск другого.
  • В настройках профиля можно отключить автоматическое закрепление (по умолчанию выключено) или полностью отключить диалоги смены прокси.
  • Автопрокси работает только в выборочном профиле и только для правил с режимом Auto (вы можете переключить любое правило вручную).

⚠️ Важно для пользователей: во время тестов происходит реальное переключение активного профиля и прокси. Это может мешать обычному сёрфингу. Запускайте тесты, когда браузер не используется для работы с сайтами.
