📖 Введение

ProxyMust – это форк расширения SmartProxy, созданный для более гибкого и удобного управления прокси-серверами. Расширение автоматически включает или отключает прокси для сайтов на основе заданных правил, позволяет тестировать работоспособность прокси, присваивать им рейтинг и сортировать по приоритету.

ProxyMust работает в Chrome, Firefox, Edge, Opera, Firefox для Android и полностью переведён на 24 языка.

⚠️ Важно: Расширение не предоставляет собственных прокси-серверов. Вы должны добавить их самостоятельно. Также оно не собирает и не передаёт никакие данные пользователя.

📦 Установка

Из магазина (рекомендуется)

  • Firefox Add-ons: перейдите в магазин, найдите «ProxyMust» и нажмите «Установить».
  • Chrome Web Store: аналогично.
  • Edge, Opera: через соответствующие магазины расширений.

Вручную (для разработчиков)

  1. Скачайте последний релиз с GitHub Releases.
  2. Распакуйте архив в отдельную папку.
  3. Chrome/Edge/Opera: откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите папку с расширением.
  4. Firefox: откройте about:debugging, нажмите «Загрузить временное дополнение», выберите любой файл в папке расширения.

🎛 Режимы работы (профили)

В попапе (иконка на панели инструментов) вы можете переключать режимы работы:

  • Напрямую (без прокси) — все запросы идут напрямую, прокси не используется.
  • Выборочный прокси — прокси включается только для сайтов, которые соответствуют правилам (черный список).
  • Всегда включён — прокси работает для всех сайтов, кроме тех, что добавлены в исключения (белый список).
  • Системный прокси — решение о использовании прокси передаётся операционной системе (настройки системы).

Вы также можете создавать собственные профили с уникальными наборами правил и привязкой к определённому прокси.

🖥 Управление прокси-серверами

На странице настроек (вкладка «Proxy Servers») вы можете управлять списком прокси.

Добавление вручную

  1. Нажмите «Add Server».
  2. Укажите:
    • Имя (для удобства)
    • Адрес (IP или домен)
    • Порт
    • Протокол (HTTP, HTTPS, SOCKS4, SOCKS5)
    • При необходимости — логин и пароль (в Chrome не поддерживается для SOCKS).
  3. Нажмите «Save».

Импорт списка

  • Нажмите «Import Proxies».
  • Вставьте текст со списком прокси или загрузите файл.
  • Поддерживаются форматы: host:port, host:port [protocol], protocol://user:pass@host:port.
  • Расширение автоматически определяет протокол и удаляет дубликаты.

Экспорт

  • Нажмите «Export Proxies» — сохранится весь список.
  • Или выберите несколько прокси в таблице, нажмите правой кнопкой мыши → «Экспорт выбранные» (контекстное меню).

🧪 Тестирование прокси

Проверьте, работает ли прокси для нужного вам сайта. Выберите сайт из выпадающего списка (или добавьте свой) и нажмите «Test». Доступны четыре типа тестов:

  • Циклический тест (работает во всех браузерах) — последовательно переключает активный профиль и каждый прокси из списка, проверяя загрузку сайта. Самый надёжный, но медленный.
  • Экспресс-циклический тест (все браузеры) — ускоренная версия, подходит для предварительной оценки.
  • Точный (медленный) тест (не работает в Firefox) — тщательная проверка, даёт точный результат.
  • Экспресс-тест (не работает в Firefox) — быстрая проверка.
⚠️ Внимание: во время циклических и экспресс-циклических тестов расширение реально переключает активный профиль и прокси. Это может мешать обычному сёрфингу. Запускайте тесты, когда браузер не используется для других задач.

Тесты можно запускать для:

  • всех прокси в таблице,
  • только выбранных (через контекстное меню),
  • текущего сайта прямо из попапа (кнопка «Test»).

📊 Рейтинг и статусы прокси

Каждый прокси получает числовой рейтинг, который автоматически изменяется по результатам тестов: +1 за успех, –1 за неудачу. Вы также можете менять рейтинг вручную через контекстное меню (правый клик).

Рядом с каждым прокси отображается статус для выбранного сайта:

  • ✅ – точно работает (свежий успех)
  • ☑️ – вероятно работает (данные устарели или успех получен для другого сайта)
  • ❓ – нет данных
  • ⛔ – не работает (свежий провал)

В настройках вы можете задать время устаревания (по умолчанию 6 часов). По истечении этого срока статус становится косвенным (☑️).

Сортировка в попапе и в таблице настроек учитывает приоритет (📌 закреплённые, ⭐ избранные) и рейтинг.

📝 Правила (фильтры)

Правила определяют, для каких сайтов включать или отключать прокси. Настраиваются в профилях (вкладка «Selective Profiles»).

Типы правил

  • Домен и поддомены – например, google.com сработает для mail.google.com.
  • Маска хоста / URL – например, *.google.com.
  • Регулярное выражение (для хоста или полного URL).
  • Точный URL – полное совпадение.
  • IP-диапазон (CIDR) – например, 192.168.1.0/24.

Добавление правил

  • Из попапа: нажмите на домен в списке «Proxyable Resources».
  • Вручную: на странице настроек в нужном профиле нажмите «Add Rule».
  • Импорт: из файлов GFWList или SwitchyOmega.

Приоритет: правила белого списка (whitelist) всегда имеют более высокий приоритет и отменяют прокси для указанных сайтов.

🖱 Контекстное меню

В таблице прокси (на странице настроек) нажмите правой кнопкой мыши на строке с прокси. Появится меню, где вы можете:

  • Изменить рейтинг (+1, –1, сброс)
  • Установить приоритет: 📌 закрепить или ⭐ добавить в избранное
  • Экспортировать выбранные прокси
  • Копировать адреса выбранных прокси
  • Удалить выбранные прокси
  • Очистить статусы для выбранных или всех прокси
  • Запустить тесты для выбранных прокси (с выбором сайта)
  • Переместить выбранные прокси вверх/вниз (в таблице)

В попапе (управляющем окне) правый клик по активному прокси позволяет:

  • Изменить рейтинг
  • Установить приоритет
  • Добавить подписочный прокси в ручной список (если клик на прокси из подписки).

📤 Импорт / экспорт

Кроме основных функций импорта/экспорта списка прокси, реализованы следующие улучшения:

  • Автоматическое переключение режима импорта: при вводе текста в поле ввода активируется режим «Текст списка прокси»; при выборе файла — режим «Файл списка прокси».
  • Экспорт выбранных: в контекстном меню таблицы можно экспортировать только отмеченные серверы.

📋 Подписки на списки прокси и правил

Подписки на списки прокси

  • Вкладка «Proxy Server Subscriptions» → «Subscribe to a list».
  • Укажите URL списка (формат: PlainText, JSON, CSV).
  • Расширение будет автоматически обновлять список по расписанию (задаётся в минутах).
  • Подписочные прокси отображаются в общем списке с пометкой источника.

Подписки на правила

  • Внутри профиля → «Rules Subscriptions» → «Subscribe to a rules list».
  • Поддерживаются форматы AutoProxy/GFWList и SwitchyOmega.
  • Правила автоматически добавляются в профиль.

🔄 Синхронизация и резервное копирование

Синхронизация

  • Включите синхронизацию в общих настройках.
  • Выберите источник: браузерная синхронизация или WebDAV-сервер.
  • При использовании WebDAV укажите URL, имя файла, логин и пароль.
  • Настройки синхронизируются автоматически при изменении.

Резервное копирование

  • Вкладка «Backup/Restore».
  • Нажмите «Create full backup» — скачается файл со всеми настройками, правилами и прокси.
  • Для восстановления выберите «Restore backup» и загрузите файл.

🎨 Темы оформления

  • В общих настройках выберите светлую, тёмную или авто (следует за темой браузера).
  • Можно указать свою пользовательскую тему — вставьте URL CSS-файла (обязательно HTTPS).
  • Поддерживаются темы из bootswatch.com.

⌨️ Горячие клавиши

Вы можете настроить сочетания клавиш в браузере (управление расширениями → клавиатурные сокращения). Доступны команды:

  • Следующий / предыдущий прокси (циклический перебор)
  • Переключение профилей: «Нет прокси», «Выборочный», «Всегда включён», «Системный»

По умолчанию: Ctrl+Shift+1 — Direct, Ctrl+Shift+2 — Selective, Ctrl+Shift+3 — Always, Ctrl+Shift+4 — System.

⚠️ Устранение проблем

Расширение не работает в приватном режиме (инкогнито)

В настройках браузера (управление расширениями) разрешите расширению работу в режиме инкогнито.

В Firefox не работают точный и экспресс-тесты

Это связано с ограничениями API браузера. Используйте циклические тесты — они работают во всех браузерах.

Прокси не подключается

  • Проверьте правильность адреса и порта.
  • Убедитесь, что прокси-сервер запущен и доступен.
  • Если используется аутентификация, проверьте логин/пароль (в Chrome аутентификация не поддерживается для SOCKS).
  • Запустите тест для проверки работоспособности.

Не отображаются статусы и рейтинги

Включите опцию «Enable rating for proxies» на вкладке «Proxy Servers».

Не удаётся импортировать список прокси

Убедитесь, что список соответствует поддерживаемым форматам. Воспользуйтесь автоматическим переключением режимов (текст/файл).

Ошибка при синхронизации через WebDAV

  • Проверьте URL и учётные данные.
  • Убедитесь, что файл доступен для записи.
  • Попробуйте выполнить резервное копирование вручную через кнопку «Backup Now».

Где посмотреть логи ошибок?

Откройте консоль разработчика (F12) на странице настроек или попапа. Включите диагностику (кнопка «diag?» внизу страницы настроек) для подробного лога.
