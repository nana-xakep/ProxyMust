ProxyMust

ProxyMust est un fork de l’extension SmartProxy. Nous respectons et remercions l’auteur original Salar Khalilzadeh pour son excellent travail. Le SmartProxy original est disponible sur https://github.com/salarcode/SmartProxy.

Utiliser des proxys n’a jamais été aussi facile qu’avec ProxyMust. Considérez-le comme une solution « configurez une fois et oubliez ». Avec ProxyMust, vous n’avez pas besoin de changer votre proxy manuellement, ni de l’activer ou le désactiver. Il vous suffit de dire à ProxyMust d’activer le proxy pour le site de votre choix en un seul clic. Après cela, chaque fois que vous visitez ce site, ProxyMust achemine automatiquement toutes vos données via le proxy, sans aucune action supplémentaire de votre part.

ProxyMust offre de nombreuses fonctionnalités, adaptées aux débutants comme aux utilisateurs avancés, notamment :

  • Activer le proxy pour un seul site dans un onglet – tout ce qui se trouve dans cet onglet utilisera automatiquement le proxy. Cette fonctionnalité s’appelle « proxy par onglet ».
  • Détecter automatiquement s’il faut activer ou désactiver le proxy pour certains sites en fonction des règles.
  • Basculer facilement entre plusieurs serveurs proxy comme serveur actif.
  • Activer le proxy pour le site actuel en un seul clic.
  • Visualiser les ressources et requêtes du site actuel et activer le proxy pour elles en un clic.
  • Changer facilement de mode proxy ou activer le proxy pour tous les domaines.
  • Sauvegarder / restaurer les paramètres et les règles.

Veuillez noter :

ProxyMust ne fournit aucun serveur proxy.
ProxyMust ne vous suit d’aucune manière.
ProxyMust est sans publicité et n’interfère pas avec le contenu des pages web.

Nouvelles fonctionnalités de ProxyMust

📊 Système de notation et de statuts

  • Pour chaque proxy et chaque site testé, le statut affiché :
    • ✅ – fonctionne certainement pour ce site (succès récent)
    • ☑️ – fonctionne probablement (succès antérieur ou obtenu sur un autre site)
    • ❓ – aucune donnée (proxy non testé pour ce site)
    • ⛔ – ne fonctionne pas (échec récent)
  • La note de chaque proxy change automatiquement en fonction des résultats des tests : +1 en cas de succès, -1 en cas d’échec.
  • Vous pouvez également modifier manuellement la note via le menu contextuel (clic droit sur une ligne de proxy dans le tableau ou sur le proxy actif dans la fenêtre contextuelle de la barre d’outils).
  • Les statuts sont considérés comme « frais » pendant un nombre d’heures configurable (6 par défaut). Si les données sont obsolètes, un statut indirect (☑️) est utilisé.

📋 Gestion de la liste des proxys

  • Menu contextuel dans le tableau des proxys (clic droit) – modifier rapidement la note, la priorité (épingler, favori), exporter la sélection, copier les adresses, supprimer, effacer statuts et notes, exécuter des tests pour les proxys sélectionnés.
  • Tri dans la fenêtre contextuelle de la barre d’outils – par note et priorité (📌 épinglés en haut, ⭐ favoris).
  • Tri dans le tableau des paramètres – par pays, protocole, note.

🚀 Tests de proxy

  • Test cyclique – bascule séquentiellement le profil actif et le proxy, vérifie le chargement du site. Fiable mais lent.
  • Test cyclique express – test accéléré qui s’arrête au premier succès. Idéal pour une évaluation rapide.
  • Test précis (lent) – plus approfondi, plus long, donne des résultats plus fiables (ne fonctionne pas dans Firefox).
  • Test express – rapide mais peut ignorer certains proxys fonctionnels. Bon pour un aperçu rapide (ne fonctionne pas dans Firefox).
  • Tests rapides depuis la fenêtre contextuelle – test du site actuel pour tous les proxys ou seulement pour les proxys d’abonnement.

⚠️ Important : pendant les tests, le profil actif et le proxy sont réellement basculés. Cela peut interférer avec la navigation normale. Lancez les tests lorsque le navigateur n’est pas utilisé pour d’autres activités.
