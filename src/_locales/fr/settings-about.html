ProxyMust

ProxyMust est un fork de l'extension SmartProxy. Nous respectons et remercions l'auteur original Salar Khalilzadeh pour son excellent travail. Le SmartProxy original est disponible sur https://github.com/salarcode/SmartProxy.

ProxyMust vous donne un contrôle total sur les connexions proxy. Vous ajoutez vos propres serveurs proxy manuellement ou via des abonnements, et le système de test automatique intégré vérifie leurs performances pour chaque site, sélectionne les meilleurs et les trie par note, priorité et fraîcheur des résultats. Avec ces paramètres, vous pouvez confier à ProxyMust le changement automatique de proxy pour les sites qui ne s'ouvrent pas sans proxy – le mode Auto Proxy trouvera un proxy fonctionnel et vous connectera au site souhaité, sans effort supplémentaire de votre part.

ProxyMust offre une variété de fonctionnalités adaptées aux débutants comme aux utilisateurs avancés, notamment :

  • Activer le proxy pour un site individuel dans un onglet – tout ce qui est ouvert dans cet onglet utilise automatiquement le proxy. Cette fonction s'appelle « proxy par onglet ».
  • Détecter automatiquement s'il faut activer ou désactiver le proxy pour certains sites en fonction de règles.
  • Basculer rapidement entre plusieurs serveurs proxy comme proxy actif.
  • Activer le proxy pour le site actuel en un seul clic.
  • Visualiser les ressources et requêtes du site actuel et activer le proxy pour elles en un clic.
  • Basculer facilement entre les modes proxy ou activer le proxy pour tous les domaines.
  • Sauvegarde et restauration des paramètres et règles.

Veuillez noter :

ProxyMust ne fournit aucun serveur proxy.
ProxyMust ne vous suit d'aucune manière.
ProxyMust est sans publicité et n'interfère pas avec le contenu des pages web.

Nouvelles fonctionnalités de ProxyMust

📊 Système de notation et de statuts

  • Pour chaque proxy et chaque site testé, le statut affiché :
    • ✅ – fonctionne certainement pour ce site (succès récent)
    • ☑️ – fonctionne probablement (succès antérieur ou obtenu pour un autre site)
    • ❓ – aucune donnée (proxy non testé pour ce site)
    • ⛔ – ne fonctionne pas (échec récent)
  • La note de chaque proxy change automatiquement en fonction des résultats des tests : +1 en cas de succès, -1 en cas d'échec.
  • Vous pouvez également modifier manuellement la note via le menu contextuel (clic droit sur une ligne de proxy dans le tableau ou sur le proxy actif dans le popup de la barre d'outils).
  • Les statuts sont considérés comme « frais » pendant un nombre d'heures configurable (6 par défaut). Si les données sont obsolètes, un statut indirect (☑️) est utilisé.

📋 Gestion de la liste des proxies

  • Menu contextuel dans le tableau des proxies (clic droit) – modifier rapidement la note, la priorité (épingler, favori), exporter la sélection, copier les adresses, supprimer, effacer les statuts et notes, exécuter des tests pour les proxies sélectionnés.
  • Tri dans le popup de la barre d'outils – par note et priorité (📌 épinglés en haut, ⭐ favoris).
  • Tri dans le tableau des paramètres – par pays, protocole, note.

🚀 Tests de proxy

  • Test cyclique – bascule séquentiellement le profil actif et le proxy, vérifie le chargement du site. Fiable mais lent.
  • Test cyclique express – test accéléré qui s'arrête au premier succès. Idéal pour une évaluation rapide.
  • Test précis (lent) – plus approfondi, plus long, donne des résultats plus fiables (ne fonctionne pas dans Firefox).
  • Test express – rapide mais peut ignorer certains proxies fonctionnels. Bon pour un aperçu rapide (ne fonctionne pas dans Firefox).
  • Tests rapides depuis le popup de la barre d'outils – tester le site actuel pour tous les proxies ou seulement pour les proxies d'abonnement.

🤖 Mode Auto Proxy

  • Pour les sites qui ne sont pas directement accessibles (par exemple en raison de restrictions régionales), Auto Proxy crée automatiquement une règle dans le profil sélectif et sélectionne un proxy fonctionnel.
  • Lors de la première visite de ce site, une boîte de dialogue propose de l'ajouter à Auto Proxy. Vous acceptez – et le système trouve immédiatement le meilleur proxy en fonction de la note, des statuts et de la priorité.
  • Après le chargement réussi de la page, vous pouvez épingler le proxy trouvé pour ce site (temporairement, jusqu'à la fermeture du navigateur) ou continuer à en chercher un autre.
  • Dans les paramètres du profil, vous pouvez désactiver l'épinglage automatique (désactivé par défaut) ou désactiver complètement les dialogues de changement de proxy.
  • Auto Proxy fonctionne uniquement dans le profil sélectif et uniquement pour les règles avec le mode Auto (vous pouvez basculer manuellement n'importe quelle règle).

⚠️ Important pour les utilisateurs : Pendant les tests, le profil actif et le proxy sont réellement basculés. Cela peut interférer avec la navigation normale. Lancez les tests lorsque le navigateur n'est pas utilisé pour d'autres activités.
