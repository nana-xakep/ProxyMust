ProxyMust

ProxyMust adalah cabang (fork) dari ekstensi SmartProxy. Kami menghormati dan berterima kasih kepada penulis asli Salar Khalilzadeh atas karya luar biasanya. SmartProxy asli dapat ditemukan di https://github.com/salarcode/SmartProxy.

Menggunakan proksi tidak pernah semudah ini dengan ProxyMust. Anggap saja sebagai solusi "atur sekali dan lupakan". Dengan ProxyMust, Anda tidak perlu mengubah proksi secara manual atau menyalakan dan mematikannya. Cukup beri tahu ProxyMust untuk mengaktifkan proksi untuk situs web yang Anda inginkan dengan sekali klik. Setelah itu, setiap kali Anda mengunjungi situs tersebut, ProxyMust akan secara otomatis mengarahkan semua data Anda melalui proksi tanpa tindakan lebih lanjut dari Anda.

ProxyMust menawarkan berbagai fitur yang cocok untuk pemula dan pengguna tingkat lanjut, termasuk:

  • Aktifkan proksi untuk satu situs pada sebuah tab, dan semua yang ada di tab tersebut akan otomatis menggunakan proksi. Fitur ini disebut proksi-per-tab.
  • Secara otomatis mendeteksi kapan harus mengaktifkan atau menonaktifkan proksi untuk situs web tertentu berdasarkan pola aturan.
  • Dengan mudah beralih antara beberapa server proksi sebagai pengaturan server proksi aktif.
  • Aktifkan proksi untuk situs saat ini hanya dengan satu klik.
  • Lihat sumber daya dan permintaan situs web saat ini dan putuskan apakah akan mengaktifkan proksi untuk mereka dengan satu klik.
  • Dengan mudah beralih antara mode proksi atau mengaktifkan proksi untuk semua domain.
  • Cadangkan dan pulihkan pengaturan serta aturan.

Harap perhatikan bahwa:

ProxyMust tidak menyediakan server proksi jenis apa pun.
ProxyMust tidak melacak Anda dengan cara apa pun.
ProxyMust bebas iklan dan tidak mengganggu halaman web dan konten.


Masukan Anda penting

Jika Anda menyukai ProxyMust, silakan beri nilai di halaman Ekstensi.
Jika Anda memiliki pertanyaan atau masalah, silakan kunjungi halaman pelacak masalah dan buka tiket untuk melaporkan masalah.


Fitur Baru ProxyMust

📊 Sistem Peringkat dan Status

  • Untuk setiap proksi dan setiap situs yang diuji, status ditampilkan:
    • ✅ – pasti berfungsi untuk situs ini (keberhasilan baru)
    • ☑️ – kemungkinan berfungsi (keberhasilan sebelumnya atau diperoleh untuk situs lain)
    • ❓ – tidak ada data (proksi belum diuji untuk situs ini)
    • ⛔ – tidak berfungsi (kegagalan baru)
  • Peringkat setiap proksi berubah secara otomatis berdasarkan hasil uji: +1 jika berhasil, -1 jika gagal.
  • Anda juga dapat mengubah peringkat secara manual melalui menu konteks (klik kanan pada baris proksi di tabel atau pada proksi aktif di popup bilah alat).
  • Status dianggap "baru" selama jumlah jam yang dapat dikonfigurasi (standar 6). Jika data sudah basi, status tidak langsung (☑️) digunakan.

📋 Mengelola Daftar Proksi

  • Menu konteks di tabel proksi (klik kanan) – ubah peringkat dengan cepat, prioritas (sematkan, bintang), ekspor yang dipilih, salin alamat, hapus, bersihkan status dan peringkat, jalankan uji untuk proksi yang dipilih.
  • Pengurutan di popup bilah alat – berdasarkan peringkat dan prioritas (📌 yang disematkan di atas, ⭐ favorit).
  • Pengurutan di tabel pengaturan – berdasarkan negara, protokol, peringkat.

🚀 Pengujian Proksi

  • Uji siklus – mengalihkan profil aktif dan proksi secara berurutan, memeriksa pemuatan situs. Andal tetapi lambat.
  • Uji siklus ekspres – pengujian dipercepat yang berhenti pada keberhasilan pertama. Baik untuk penilaian cepat.
  • Uji presisi (lambat) – lebih teliti, memakan waktu lebih lama, memberikan hasil yang lebih dapat diandalkan (tidak berfungsi di Firefox).
  • Uji ekspres – cepat tetapi mungkin melewatkan beberapa proksi yang berfungsi. Baik untuk gambaran cepat (tidak berfungsi di Firefox).
  • Uji cepat dari popup bilah alat – uji situs saat ini untuk semua proksi atau hanya untuk proksi langganan.

⚠️ Penting bagi pengguna: Selama pengujian, profil aktif dan proksi benar-benar dialihkan. Ini dapat mengganggu penjelajahan normal. Jalankan pengujian saat peramban tidak digunakan untuk aktivitas lain.
