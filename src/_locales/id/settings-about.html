ProxyMust

ProxyMust adalah cabang dari ekstensi SmartProxy. Kami menghormati dan berterima kasih kepada penulis asli Salar Khalilzadeh atas karya luar biasanya. SmartProxy asli dapat ditemukan di https://github.com/salarcode/SmartProxy.

ProxyMust memberi Anda kendali penuh atas koneksi proxy. Anda menambahkan server proxy sendiri secara manual atau melalui langganan, dan sistem pengujian otomatis terintegrasi memeriksa kinerjanya untuk setiap situs, memilih yang terbaik, dan mengurutkannya berdasarkan peringkat, prioritas, dan kesegaran hasil. Dengan pengaturan ini, Anda dapat mempercayakan ProxyMust untuk mengganti proxy secara otomatis untuk situs yang tidak terbuka tanpa proxy – mode Auto Proxy akan menemukan proxy yang berfungsi dan menghubungkan Anda ke situs yang diinginkan, tanpa usaha ekstra dari pihak Anda.

ProxyMust menawarkan berbagai fitur yang cocok untuk pemula dan pengguna tingkat lanjut, termasuk:

  • Mengaktifkan proxy untuk satu situs di tab – semua yang dibuka di tab tersebut secara otomatis menggunakan proxy. Fitur ini disebut "proxy per tab".
  • Mendeteksi secara otomatis apakah akan mengaktifkan atau menonaktifkan proxy untuk situs tertentu berdasarkan aturan.
  • Beralih dengan cepat di antara beberapa server proxy sebagai proxy aktif.
  • Mengaktifkan proxy untuk situs saat ini dengan satu klik.
  • Melihat sumber daya dan permintaan situs saat ini dan mengaktifkan proxy untuk mereka dengan satu klik.
  • Beralih dengan mudah antara mode proxy atau mengaktifkan proxy untuk semua domain.
  • Cadangan dan pemulihan pengaturan dan aturan.

Harap diperhatikan:

ProxyMust tidak menyediakan server proxy apa pun.
ProxyMust tidak melacak Anda dengan cara apa pun.
ProxyMust bebas iklan dan tidak mengganggu konten halaman web.


Masukan Anda penting

Jika Anda menyukai ProxyMust, silakan beri peringkat di halaman ekstensi.
Jika Anda memiliki pertanyaan atau masalah, kunjungi pelacak masalah dan buka tiket untuk melaporkan masalah.


Fitur baru ProxyMust

📊 Sistem peringkat dan status

  • Untuk setiap proxy dan setiap situs yang diuji, status ditampilkan:
    • ✅ – pasti berfungsi untuk situs ini (keberhasilan segar)
    • ☑️ – kemungkinan berfungsi (keberhasilan sebelumnya atau diperoleh untuk situs lain)
    • ❓ – tidak ada data (proxy belum diuji untuk situs ini)
    • ⛔ – tidak berfungsi (kegagalan segar)
  • Peringkat setiap proxy berubah secara otomatis berdasarkan hasil tes: +1 jika berhasil, -1 jika gagal.
  • Anda juga dapat mengubah peringkat secara manual melalui menu konteks (klik kanan pada baris proxy di tabel atau pada proxy aktif di popup toolbar).
  • Status dianggap "segar" selama sejumlah jam yang dapat dikonfigurasi (default 6). Jika data basi, status tidak langsung (☑️) digunakan.

📋 Mengelola daftar proxy

  • Menu konteks di tabel proxy (klik kanan) – ubah peringkat dengan cepat, prioritas (pin, bintang), ekspor yang dipilih, salin alamat, hapus, hapus status dan peringkat, jalankan tes untuk proxy yang dipilih.
  • Pengurutan di popup toolbar – berdasarkan peringkat dan prioritas (📌 disematkan di atas, ⭐ favorit).
  • Pengurutan di tabel pengaturan – berdasarkan negara, protokol, peringkat.

🚀 Pengujian proxy

  • Uji siklus – mengalihkan profil aktif dan proxy secara berurutan, memeriksa pemuatan situs. Andal tetapi lambat.
  • Uji siklus ekspres – pengujian dipercepat yang berhenti pada keberhasilan apa pun. Cocok untuk penilaian awal.
  • Uji presisi (lambat) – pemeriksaan lebih teliti, memakan waktu lebih lama, tetapi memberikan hasil lebih andal (tidak berfungsi di Firefox).
  • Uji ekspres – pemeriksaan cepat, tetapi mungkin melewatkan beberapa proxy yang berfungsi. Cocok untuk penilaian awal (tidak berfungsi di Firefox).
  • Uji cepat dari toolbar – periksa situs saat ini untuk semua proxy atau hanya untuk proxy langganan.

🤖 Mode Auto Proxy

  • Untuk situs yang tidak dapat diakses secara langsung (misalnya karena pembatasan regional), Auto Proxy secara otomatis membuat aturan di profil selektif dan memilih proxy yang berfungsi.
  • Saat Anda pertama kali mengunjungi situs tersebut, dialog muncul menyarankan untuk menambahkannya ke Auto Proxy. Anda setuju – dan sistem segera menemukan proxy terbaik berdasarkan peringkat, status, dan prioritas.
  • Setelah halaman berhasil dimuat, Anda dapat menyematkan proxy yang ditemukan untuk situs ini (sementara, hingga browser ditutup) atau melanjutkan pencarian yang lain.
  • Di pengaturan profil, Anda dapat menonaktifkan penyematan otomatis (default nonaktif) atau menonaktifkan sepenuhnya dialog perubahan proxy.
  • Auto Proxy hanya berfungsi di profil selektif dan hanya untuk aturan dengan mode Auto (Anda dapat mengganti aturan apa pun secara manual).

⚠️ Penting bagi pengguna: Selama pengujian, profil aktif dan proxy benar-benar dialihkan. Ini dapat mengganggu penjelajahan normal. Jalankan pengujian saat browser tidak digunakan untuk aktivitas lain.
