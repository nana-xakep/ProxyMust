ProxyMust

O ProxyMust é um fork da extensão SmartProxy. Respeitamos e agradecemos ao autor original Salar Khalilzadeh pelo seu excelente trabalho. O SmartProxy original pode ser encontrado em https://github.com/salarcode/SmartProxy.

Usar proxies não poderia ser mais fácil com o ProxyMust. Pense nele como uma solução de configurar uma vez e esquecer. Com o ProxyMust não precisa de alterar manualmente o seu proxy ou ligá-lo e desligá-lo. Tudo o que precisa fazer é dizer ao ProxyMust que pretende ativar o proxy para o site desejado com apenas um clique. Depois disso, quando visitar esse site específico, o ProxyMust atuará e todos os seus dados para esse site serão transferidos através do proxy, sem que faça nada.

O ProxyMust oferece uma variedade de funcionalidades adequadas tanto para principiantes como para utilizadores avançados, incluindo:

  • Ativar o proxy para um único site num separador – tudo nesse separador usará automaticamente o proxy. Esta funcionalidade chama-se proxy-por-separador.
  • Detetar automaticamente quando ativar ou desativar o proxy para certos sites com base em padrões de regras.
  • Alternar facilmente entre vários servidores proxy como o seu servidor proxy ativo.
  • Ativar o proxy para o site atual com apenas um clique.
  • Ver os recursos e pedidos do site atual e decidir se ativa o proxy para eles com um clique.
  • Alternar facilmente entre modos de proxy ou ativar o proxy para todos os domínios.
  • Cópia de segurança e restauro de definições e regras.

Por favor, note que:

O ProxyMust não fornece qualquer tipo de servidores proxy.
O ProxyMust não o rastreia de forma alguma.
O ProxyMust é livre de anúncios e não interfere com páginas web e conteúdos.

Novas funcionalidades do ProxyMust

📊 Sistema de classificação e estados

  • Para cada proxy e cada site testado, é mostrado o estado:
    • ✅ – definitivamente funciona para este site (sucesso recente)
    • ☑️ – provavelmente funciona (sucesso foi anterior ou obtido para outro site)
    • ❓ – sem dados (proxy não testado para este site)
    • ⛔ – não funciona (falha recente)
  • A classificação de cada proxy muda automaticamente com base nos resultados dos testes: +1 em caso de sucesso, -1 em caso de falha.
  • Também pode alterar manualmente a classificação através do menu de contexto (clique direito numa linha de proxy na tabela ou no proxy ativo no popup da barra de ferramentas).
  • Os estados são considerados "frescos" durante um número configurável de horas (padrão 6). Se os dados estiverem desatualizados, é usado um estado indireto (☑️).

📋 Gerir a lista de proxies

  • Menu de contexto na tabela de proxies (clique direito) – alterar rapidamente a classificação, prioridade (fixar, favorito), exportar selecionados, copiar endereços, eliminar, limpar estados e classificações, executar testes para os proxies selecionados.
  • Ordenação no popup da barra de ferramentas – por classificação e prioridade (📌 fixados no topo, ⭐ favoritos).
  • Ordenação na tabela de definições – por país, protocolo, classificação.

🚀 Testes de proxy

  • Teste cíclico – comuta sequencialmente o perfil ativo e o proxy, verificando o carregamento do site. Fiável mas lento.
  • Teste cíclico rápido – teste acelerado que para no primeiro sucesso. Bom para uma avaliação rápida.
  • Teste preciso (lento) – mais completo, demora mais tempo, dá resultados mais fiáveis (não funciona no Firefox).
  • Teste rápido – rápido mas pode ignorar alguns proxies funcionais. Bom para uma visão geral rápida (não funciona no Firefox).
  • Testes rápidos a partir do popup da barra de ferramentas – testar o site atual para todos os proxies ou apenas para proxies de subscrição.

⚠️ Importante para os utilizadores: Durante os testes, o perfil ativo e o proxy são efetivamente trocados. Isto pode interferir com a navegação normal. Execute os testes quando o browser não estiver a ser usado para outras atividades.
