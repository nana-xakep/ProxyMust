ProxyMust

ProxyMust é um fork da extensão SmartProxy. Respeitamos e agradecemos ao autor original Salar Khalilzadeh pelo seu excelente trabalho. O SmartProxy original pode ser encontrado em https://github.com/salarcode/SmartProxy.

ProxyMust dá-lhe controlo total sobre as ligações proxy. Você adiciona os seus próprios servidores proxy manualmente ou através de assinaturas, e o sistema de teste automático integrado verifica o desempenho de cada um para cada site, seleciona os melhores e ordena-os por classificação, prioridade e frescura dos resultados. Com estas definições, pode confiar ao ProxyMust a mudança automática de proxies para sites que não abrem sem proxy – o modo Auto Proxy encontrará um proxy funcional e ligá-lo-á ao site pretendido, sem esforço extra da sua parte.

ProxyMust oferece uma variedade de funcionalidades adequadas tanto para principiantes como para utilizadores avançados, incluindo:

  • Ativar proxy para um único site num separador – tudo o que for aberto nesse separador usa automaticamente o proxy. Esta funcionalidade chama-se "proxy por separador".
  • Detetar automaticamente se deve ativar ou desativar o proxy para determinados sites com base em regras.
  • Mudar rapidamente entre vários servidores proxy como proxy ativo.
  • Ativar proxy para o site atual com um único clique.
  • Ver os recursos e pedidos do site atual e ativar proxy para eles com um clique.
  • Mudar facilmente entre modos de proxy ou ativar proxy para todos os domínios.
  • Cópia de segurança e restauro de definições e regras.

Nota:

O ProxyMust não fornece quaisquer servidores proxy.
O ProxyMust não o rastreia de forma alguma.
O ProxyMust é livre de anúncios e não interfere com o conteúdo das páginas web.

Novas funcionalidades do ProxyMust

📊 Sistema de classificação e estados

  • Para cada proxy e cada site testado, é mostrado o estado:
    • ✅ – funciona definitivamente para este site (sucesso recente)
    • ☑️ – provavelmente funciona (sucesso anterior ou obtido para outro site)
    • ❓ – sem dados (proxy não testado para este site)
    • ⛔ – não funciona (falha recente)
  • A classificação de cada proxy muda automaticamente com base nos resultados dos testes: +1 em caso de sucesso, -1 em caso de falha.
  • Também pode alterar manualmente a classificação através do menu de contexto (clique direito numa linha de proxy na tabela ou no proxy ativo no popup da barra de ferramentas).
  • Os estados são considerados "frescos" durante um número configurável de horas (padrão 6). Se os dados estiverem desatualizados, é usado um estado indireto (☑️).

📋 Gestão da lista de proxies

  • Menu de contexto na tabela de proxies (clique direito) – alterar rapidamente a classificação, prioridade (fixar, favorito), exportar selecionados, copiar endereços, eliminar, limpar estados e classificações, executar testes para os proxies selecionados.
  • Ordenação no popup da barra de ferramentas – por classificação e prioridade (📌 fixados no topo, ⭐ favoritos).
  • Ordenação na tabela de definições – por país, protocolo, classificação.

🚀 Testes de proxy

  • Teste cíclico – comutação sequencial do perfil ativo e do proxy, verificando o carregamento do site. Fiável mas lento.
  • Teste cíclico rápido – teste acelerado que para no primeiro sucesso. Bom para uma avaliação rápida.
  • Teste preciso (lento) – mais completo, demora mais tempo, dá resultados mais fiáveis (não funciona no Firefox).
  • Teste rápido – rápido, mas pode ignorar alguns proxies funcionais. Bom para uma visão geral rápida (não funciona no Firefox).
  • Testes rápidos a partir do popup da barra de ferramentas – testar o site atual para todos os proxies ou apenas para proxies de assinatura.

🤖 Modo Auto Proxy

  • Para sites que não estão diretamente acessíveis (por exemplo, devido a restrições regionais), o Auto Proxy cria automaticamente uma regra no perfil seletivo e seleciona um proxy funcional.
  • Quando visita um desses sites pela primeira vez, aparece um diálogo sugerindo adicioná-lo ao Auto Proxy. Aceita – e o sistema encontra imediatamente o melhor proxy com base na classificação, estados e prioridade.
  • Após o carregamento bem-sucedido da página, pode fixar o proxy encontrado para este site (temporariamente, até fechar o navegador) ou continuar a procurar outro.
  • Nas definições do perfil, pode desativar a fixação automática (desativada por padrão) ou desativar completamente os diálogos de mudança de proxy.
  • O Auto Proxy funciona apenas no perfil seletivo e apenas para regras com o modo Auto (pode alternar manualmente qualquer regra).

⚠️ Importante para utilizadores: Durante os testes, o perfil ativo e o proxy são efetivamente trocados. Isso pode interferir com a navegação normal. Execute os testes quando o navegador não estiver a ser utilizado para outras atividades.
