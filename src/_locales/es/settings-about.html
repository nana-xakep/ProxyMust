ProxyMust

ProxyMust es un fork de la extensión SmartProxy. Respetamos y agradecemos al autor original Salar Khalilzadeh por su excelente trabajo. El SmartProxy original se puede encontrar en https://github.com/salarcode/SmartProxy.

Usar proxies es más fácil que nunca con ProxyMust. Piénselo como una solución de configurar una vez y olvidar. Con ProxyMust no necesita cambiar su configuración de proxy manualmente ni encenderlo y apagarlo. Simplemente dígale a ProxyMust que habilite el proxy para su sitio web deseado con solo un clic. Después de eso, cada vez que visite ese sitio específico, ProxyMust enrutará automáticamente todos sus datos a través del proxy, sin que usted haga nada.

ProxyMust ofrece una variedad de características adecuadas tanto para principiantes como para usuarios avanzados, que incluyen:

  • Habilitar el proxy para un solo sitio en una pestaña: todo en esa pestaña usará automáticamente el proxy. Esta característica se llama "proxy por pestaña".
  • Detectar automáticamente cuándo habilitar o deshabilitar el proxy para ciertos sitios web basándose en reglas.
  • Cambiar fácilmente entre múltiples servidores proxy como su servidor proxy activo.
  • Habilitar el proxy para el sitio actual con un solo clic.
  • Visualizar los recursos y solicitudes del sitio actual y decidir si habilitar el proxy para ellos con un solo clic.
  • Cambiar fácilmente entre modos de proxy o habilitar el proxy para todos los dominios.
  • Copia de seguridad y restauración de configuraciones y reglas.

Tenga en cuenta que:

ProxyMust no proporciona ningún tipo de servidores proxy.
ProxyMust no lo rastrea de ninguna manera.
ProxyMust está libre de anuncios y no interfiere con las páginas web ni el contenido.

Nuevas características de ProxyMust

📊 Sistema de puntuación y estados

  • Para cada proxy y cada sitio probado, se muestra el estado:
    • ✅ – definitivamente funciona para este sitio (éxito reciente)
    • ☑️ – probablemente funciona (el éxito fue anterior o se obtuvo para otro sitio)
    • ❓ – sin datos (proxy no probado para este sitio)
    • ⛔ – no funciona (fallo reciente)
  • La puntuación de cada proxy cambia automáticamente según los resultados de las pruebas: +1 en éxito, -1 en fallo.
  • También puede cambiar la puntuación manualmente mediante el menú contextual (clic derecho en una fila de proxy en la tabla o en el proxy activo en la ventana emergente de la barra de herramientas).
  • Los estados se consideran "recientes" durante un número configurable de horas (por defecto 6). Si los datos están obsoletos, se usa un estado indirecto (☑️).

📋 Gestión de la lista de proxies

  • Menú contextual en la tabla de proxies (clic derecho) – cambio rápido de puntuación, prioridad (fijar, favorito), exportar seleccionados, copiar direcciones, eliminar, limpiar estados y puntuaciones, ejecutar pruebas para los proxies seleccionados.
  • Ordenación en la ventana emergente de la barra de herramientas – por puntuación y prioridad (📌 fijados arriba, ⭐ favoritos).
  • Ordenación en la tabla de configuración – por país, protocolo, puntuación.

🚀 Pruebas de proxy

  • Prueba cíclica – cambia secuencialmente el perfil activo y el proxy, verificando la carga del sitio. Confiable pero lento.
  • Prueba cíclica exprés – prueba acelerada que se detiene en el primer éxito. Buena para una evaluación rápida.
  • Prueba precisa (lenta) – más exhaustiva, lleva más tiempo, da resultados más fiables (no funciona en Firefox).
  • Prueba exprés – rápida pero puede omitir algunos proxies funcionales. Buena para una visión general rápida (no funciona en Firefox).
  • Pruebas rápidas desde la ventana emergente de la barra de herramientas – prueba del sitio actual para todos los proxies o solo para proxies de suscripción.

⚠️ Importante para los usuarios: Durante las pruebas, el perfil activo y el proxy se cambian realmente. Esto puede interferir con la navegación normal. Ejecute las pruebas cuando el navegador no se esté utilizando para otras actividades.
