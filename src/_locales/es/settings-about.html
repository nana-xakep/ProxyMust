ProxyMust

ProxyMust es un fork de la extensión SmartProxy. Respetamos y agradecemos al autor original Salar Khalilzadeh por su excelente trabajo. El SmartProxy original se puede encontrar en https://github.com/salarcode/SmartProxy.

ProxyMust le brinda control total sobre las conexiones proxy. Usted agrega sus propios servidores proxy de forma manual o mediante suscripciones, y el sistema de prueba automática incorporado verifica su rendimiento para cada sitio web, selecciona los mejores y los ordena por calificación, prioridad y frescura de los resultados. Con esta configuración, puede confiar en ProxyMust para cambiar automáticamente los proxies para sitios que no se abren sin un proxy: el modo Auto Proxy encontrará un proxy funcional y lo conectará al sitio deseado, sin esfuerzo adicional de su parte.

ProxyMust ofrece una variedad de funciones adecuadas tanto para principiantes como para usuarios avanzados, que incluyen:

  • Habilitar proxy para un sitio individual en una pestaña: todo lo que se abre en esa pestaña usa automáticamente el proxy. Esta función se llama "proxy por pestaña".
  • Detectar automáticamente si se debe habilitar o deshabilitar el proxy para ciertos sitios según reglas.
  • Cambiar rápidamente entre varios servidores proxy como proxy activo.
  • Habilitar proxy para el sitio actual con un solo clic.
  • Ver los recursos y solicitudes del sitio actual y habilitar el proxy para ellos con un clic.
  • Cambiar fácilmente entre modos de proxy o habilitar proxy para todos los dominios.
  • Copias de seguridad y restauración de configuraciones y reglas.

Tenga en cuenta:

ProxyMust no proporciona ningún servidor proxy.
ProxyMust no lo rastrea de ninguna manera.
ProxyMust está libre de publicidad y no interfiere con el contenido de las páginas web.

Nuevas funciones de ProxyMust

📊 Sistema de calificación y estados

  • Para cada proxy y cada sitio probado, se muestra el estado:
    • ✅ – definitivamente funciona para este sitio (éxito reciente)
    • ☑️ – probablemente funciona (el éxito fue anterior o se obtuvo para otro sitio)
    • ❓ – sin datos (proxy no probado para este sitio)
    • ⛔ – no funciona (fallo reciente)
  • La calificación de cada proxy cambia automáticamente según los resultados de las pruebas: +1 en caso de éxito, -1 en caso de fallo.
  • También puede cambiar la calificación manualmente mediante el menú contextual (clic derecho en una fila de proxy en la tabla o en el proxy activo en el popup de la barra de herramientas).
  • Los estados se consideran "frescos" durante un número configurable de horas (por defecto 6). Si los datos están obsoletos, se usa un estado indirecto (☑️).

📋 Gestión de la lista de proxies

  • Menú contextual en la tabla de proxies (clic derecho) – cambiar rápidamente la calificación, prioridad (fijar, favorito), exportar seleccionados, copiar direcciones, eliminar, borrar estados y calificaciones, ejecutar pruebas para los proxies seleccionados.
  • Ordenamiento en el popup de la barra de herramientas – por calificación y prioridad (📌 fijados arriba, ⭐ favoritos).
  • Ordenamiento en la tabla de configuración – por país, protocolo, calificación.

🚀 Pruebas de proxy

  • Prueba cíclica – cambio secuencial del perfil activo y el proxy, verificando la carga del sitio. Fiable pero lento.
  • Prueba cíclica exprés – prueba acelerada que se detiene en el primer éxito. Buena para una evaluación rápida.
  • Prueba precisa (lenta) – más exhaustiva, toma más tiempo, da resultados más fiables (no funciona en Firefox).
  • Prueba exprés – rápida pero puede omitir algunos proxies funcionales. Buena para una visión general rápida (no funciona en Firefox).
  • Pruebas rápidas desde el popup de la barra de herramientas – probar el sitio actual para todos los proxies o solo para proxies de suscripción.

🤖 Modo Auto Proxy

  • Para sitios que no son accesibles directamente (por ejemplo, debido a restricciones regionales), Auto Proxy crea automáticamente una regla en el perfil selectivo y selecciona un proxy funcional.
  • Cuando visita por primera vez dicho sitio, aparece un diálogo sugiriendo agregarlo a Auto Proxy. Usted acepta – y el sistema encuentra inmediatamente el mejor proxy según la calificación, estados y prioridad.
  • Después de que la página se cargue correctamente, puede fijar el proxy encontrado para este sitio (temporalmente, hasta que se cierre el navegador) o continuar buscando otro.
  • En la configuración del perfil, puede desactivar el fijado automático (desactivado por defecto) o deshabilitar completamente los diálogos de cambio de proxy.
  • Auto Proxy funciona solo en el perfil selectivo y solo para reglas con el modo Auto (puede cambiar manualmente cualquier regla).

⚠️ Importante para los usuarios: Durante las pruebas, el perfil activo y el proxy se cambian realmente. Esto puede interferir con la navegación normal. Ejecute las pruebas cuando el navegador no se esté utilizando para otras actividades.
