# Список изменений

Все значимые изменения в этом проекте будут задокументированы в этом файле.

## [1.0.2] – 2026-06-21

### Добавлено
- **Новая настройка: "Enable direct IP detection"** – чекбокс в разделе "Proxy Test" на странице настроек. Отключён по умолчанию для защиты приватности пользователя: реальный IP не отправляется внешним IP-сервисам во время тестов. При включении тесты используют прямой IP для сравнения; при отключении – хост проверяемого прокси (если он является IP-адресом) используется как эталон для определения косвенного успеха.
- **Новый статус "ip-only" (❔)** – введён для случаев, когда IP-адрес успешно получен через прокси, но отличается от IP хоста (при отключённом чекбоксе передачи прямого IP для сравнения), а основная тестовая страница не загружается. Этот статус отображается отдельно от косвенного успеха и не влияет на рейтинг прокси.
- **Тестирование прокси через fetch** – создание видимых/невидимых вкладок заменено на запросы через `fetch` API как для основного URL, так и для проверки IP-сервисов. Это устраняет нежелательные скачивания, ускоряет тестирование и предотвращает засорение истории браузера.
- Локализация новой настройки на всех поддерживаемых языках.
- Централизованное управление IP-сервисами (`IpServiceManager`) для кэширования прямого IP и ранжированных IP-сервисов.
- Унифицированное ядро проверки прокси (`ProxyCheckerCore`) с раздельной логикой для точных/экспресс-тестов и циклических тестов.
- Централизованный сохранитель результатов (`ResultSaver`) для рейтинга, autoStatus и обновлений прогресса.
- Менеджер тестов (`TestManager`) для блокировки тестов, переключения профилей и прокси.

### Изменено
- **Логика косвенного успеха** – при отключённом определении прямого IP совпадение IP, полученного через прокси, с хостом прокси теперь считается косвенным успехом (☑️), что корректно указывает на то, что прокси возвращает свой собственный IP. Ранее такое совпадение ошибочно интерпретировалось как обнаружение прямого IP и приводило к ненужным повторным проверкам. Если IP отличается от хоста и страница не загружается, вместо этого присваивается новый статус `ip-only` (❔).
- **Классификация типов тестов** – унифицированы типы тестов по всей кодовой базе: `'precise'` для точных тестов, `'quick'` для экспресс-тестов, `'cycle'` для циклических тестов и `'express-cycle'` для экспресс-циклических тестов. Это устраняет путаницу в логах и блокировке тестов.
- **Мгновенное применение прокси в циклических тестах** – добавлены вызовы `ProxyEngine.updateBrowsersProxyConfig()` при переключении профиля и прокси, что обеспечивает применение настроек браузера без задержек, восстанавливая оригинальную производительность циклических тестов.
- **Сообщения в консоли** – теперь чётко указывают эталон, используемый для сравнения IP (прямой IP или хост прокси), в зависимости от настройки, и отображают соответствующий символ статуса (✅, ☑️, ❔, ⛔) для каждого результата теста.
- Рефакторинг всех типов тестов (точный, экспресс, циклический, экспресс-циклический) с использованием общих модулей, что устранило ~70% дублирующегося кода.
- Улучшено отображение статусов тестов: косвенный успех теперь корректно отображается как ☑️ во время выполнения теста.
- Удаление прокси через клавишу Delete теперь сохраняется немедленно.

### Исправлено
- Ошибка компиляции TypeScript из-за недопустимого типа `'precise'` в `TestManager.tryStartTest()` – расширен набор допустимых типов тестов.
- Некорректное поведение при отключённом определении прямого IP, когда тесты безосновательно перезапускались из-за ложного срабатывания обнаружения прямого IP.
- Уменьшено количество ошибок "Invalid tab ID" за счёт сокращения повторных попыток.
- Исправлена проблема, при которой прокси, удалённые через клавишу Delete, появлялись снова после перезагрузки страницы.
- Исправлены ошибки компиляции TypeScript, связанные с отсутствующими экспортами и неиспользуемыми импортами.
- Исправлен отсутствующий импорт `TestManager` в `Core.ts`.
- Исправлен некорректный `statusType` для косвенного успеха в нециклических тестах.
- **Исправлены нежелательные скачивания файлов** во время тестирования – проверка IP-сервисов через вкладки заменена на вызовы `fetch`, что устранило автоматические скачивания пустых или повреждённых файлов.
- **Исправлена ссылка на страницу рейтинга** – теперь ведёт на правильную страницу ProxyMust в Firefox Add-ons.

### Изменено (инфраструктура)
- Добавлены автоматические ссылки на магазины расширений в зависимости от браузера для будущей публикации в Chrome.

### Удалено
- Дублирующийся код в проверщиках и тестерах прокси.
- Создание видимых и невидимых вкладок при тестировании прокси (заменено на проверки через `fetch`).

## [1.0.0] – 2026-06-15

### Добавлено (форк от SmartProxy 2.1)
- Ребрендинг: SmartProxy → ProxyMust, Smart Proxy → Selective Proxy, Smart Profiles → Selective Profiles.
- Система рейтинга прокси (ручное изменение, автоматическое на основе результатов тестов).
- Отображение статусов тестов для каждого прокси и сайта (✅ ☑️ ❓ ⛔).
- Тестирование прокси: точный тест, экспресс-тест, циклический тест, экспресс-циклический тест.
- Контекстное меню в таблице прокси (правый клик): изменение рейтинга, приоритет (pin/star), экспорт выбранных, копирование адресов, удаление, очистка статусов, запуск тестов для выбранных прокси.
- Сортировка по рейтингу и приоритету (в попапе и таблице настроек).
- Флаги стран (на основе IP2Location).
- Возможность ручного добавления/удаления тестовых сайтов.
- Настраиваемое время устаревания для статусов тестов.
- Кнопка "Add working" в попапе – добавление успешно протестированных подписочных прокси в ручной список.
- Новые языки локализации: бенгальский (bn), хинди (hi), японский (ja), корейский (ko), португальский (pt), урду (ur), вьетнамский (vi).
- Улучшенный импорт: автоматическое переключение между текстовым/файловым режимом; экспорт выбранных прокси через контекстное меню.

### Изменено

- Локализация для 24 языков (пересмотрены оригинальные языки SmartProxy, добавлены новые).
- Имя файла резервной копии WebDAV по умолчанию: `proxymust_settings.json`.
- Имя файла экспорта списка прокси: `ProxyMust-Servers-export.txt`.
- В подвале страницы настроек отображается `ProxyMust 1.0.0 (based on SmartProxy 2.1)`.
- Удалён блок партнёрской рекламы (AvaProxy).
- Отключены уведомления об обновлениях (UpdateManager).

### Исправлено
- Исправлена структура `settings.html` (закрыта таблица, корректное размещение элементов рейтинга и управления тестами).
- Исправлены ошибки инициализации DataTables на пустых таблицах.

- Код проверки обновлений (UpdateManager).
- Партнёрская реклама (AvaProxy).
