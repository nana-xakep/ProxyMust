📖 Введение

ProxyMust — это форк расширения SmartProxy, созданный для более гибкого и удобного управления прокси-серверами. Расширение автоматически включает или отключает прокси для сайтов на основе заданных правил, позволяет проверять работоспособность прокси, присваивать им рейтинг и сортировать по приоритету.

ProxyMust работает в Chrome, Firefox, Edge, Opera и Firefox для Android и полностью переведён на 24 языка.

⚠️ Важно: Это расширение не предоставляет собственных прокси-серверов. Вы должны добавить их самостоятельно. Оно также не собирает и не передаёт никакие пользовательские данные.

📦 Установка

Из магазина (рекомендуется)

  • Firefox Add-ons: перейдите в магазин, найдите "ProxyMust" и нажмите «Установить».
  • Chrome Web Store: аналогично.
  • Edge, Opera: через соответствующие магазины расширений.

Вручную (для разработчиков)

  1. Скачайте последний релиз с GitHub Releases.
  2. Распакуйте архив в отдельную папку.
  3. Chrome/Edge/Opera: откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку с расширением.
  4. Firefox: откройте about:debugging, нажмите «Загрузить временное дополнение», и выберите любой файл в папке расширения.

🎛 Режимы работы (профили)

Во всплывающем окне (значок на панели инструментов) можно переключать режимы работы:

  • Прямое соединение (без прокси) — все запросы идут напрямую, прокси не используется.
  • Выборочный прокси — прокси включается только для сайтов, которые соответствуют правилам (чёрный список).
  • Всегда включён — прокси работает для всех сайтов, кроме добавленных в исключения (белый список).
  • Системный прокси — решение об использовании прокси делегируется операционной системе (системные настройки).

Вы также можете создавать пользовательские профили с уникальными наборами правил и привязкой к конкретному прокси.

🖥 Управление прокси-серверами

На странице настроек (вкладка «Прокси-серверы») вы можете управлять списком прокси.

Добавление вручную

  1. Нажмите «Добавить сервер».
  2. Укажите:
    • Имя (для удобства)
    • Адрес (IP или домен)
    • Порт
    • Протокол (HTTP, HTTPS, SOCKS4, SOCKS5)
    • При необходимости — логин и пароль (не поддерживается для SOCKS в Chrome).
  3. Нажмите «Сохранить».

Импорт списка

  • Нажмите «Импорт прокси».
  • Вставьте текст со списком прокси или загрузите файл.
  • Поддерживаемые форматы: host:port, host:port [protocol], protocol://user:pass@host:port.
  • Расширение автоматически определяет протокол и удаляет дубликаты.

Экспорт

  • Нажмите «Экспорт прокси» — весь список будет сохранён.
  • Или выделите несколько прокси в таблице, нажмите правой кнопкой мыши → «Экспортировать выбранные» (контекстное меню).

🧪 Тестирование прокси

Проверьте, работает ли прокси для нужного вам сайта. Выберите сайт из выпадающего списка (или добавьте свой) и нажмите «Тест». Доступны четыре типа тестов:

  • Циклический тест (работает во всех браузерах) — последовательно переключает активный профиль и каждый прокси в списке, проверяя загрузку сайта. Самый надёжный, но медленный.
  • Экспресс-циклический тест (все браузеры) — ускоренная версия, подходит для предварительной оценки.
  • Точный (медленный) тест (не работает в Firefox) — тщательная проверка, даёт точный результат.
  • Экспресс-тест (не работает в Firefox) — быстрая проверка.
🛡️ Управление приватностью: В настройках вы можете включить или отключить чекбокс "Enable direct IP detection" (по умолчанию выключен). Когда выключен, ваш реальный IP никогда не отправляется внешним IP-сервисам – расширение полагается только на проверки загрузки сайта и сравнивает хост прокси (если это IP-адрес) с IP, полученным через прокси. Когда включён, ваш IP отправляется IP-сервисам для более точных результатов (исключается статус ❔).
⚡ Производительность и приватность: ProxyMust выполняет все тесты без открытия вкладок браузера. Все проверки (загрузка основной страницы и запросы к IP-сервисам) выполняются через fetch-запросы. Это означает, что не добавляются записи в историю, не скачиваются нежелательные файлы, а тестирование происходит быстрее.

Тесты можно запускать для:

  • всех прокси в таблице,
  • только выделенных (через контекстное меню),
  • текущего сайта прямо из всплывающего окна (кнопка «Тест»).

О таймаутах: Таймер теста автоматически продлевается при каждом обновлении прогресса, поэтому длительные тесты (например, сотни прокси) не будут прерваны преждевременно.

📊 Рейтинг и статусы прокси

Каждый прокси получает числовой рейтинг, который автоматически меняется по результатам тестов: +1 за успех, –1 за провал. Вы также можете изменить рейтинг вручную через контекстное меню (правая кнопка мыши).

Рядом с каждым прокси отображается статус для выбранного сайта:

  • ✅ – точно работает (свежий успех)
  • ☑️ – вероятно работает (данные устарели или успех получен для другого сайта)
  • ❔ – IP получен, но страница не загрузилась (появляется только когда определение прямого IP отключено и полученный IP отличается от хоста прокси)
  • ❓ – нет данных
  • ⛔ – не работает (свежий провал)

В настройках можно задать время устаревания (по умолчанию 6 часов). После этого периода статус становится косвенным (☑️).

Сортировка во всплывающем окне и в таблице настроек учитывает приоритет (📌 закреплённые, ⭐ избранные) и рейтинг.

Статус ❔ не влияет на рейтинг прокси, поскольку неясно, работает ли прокси на самом деле (IP получен, но сайт не загрузился).

📝 Правила (фильтры)

Правила определяют, для каких сайтов включать или отключать прокси. Они настраиваются в профилях (вкладка «Выборочные профили»).

Типы правил

  • Домен и поддомены – например, google.com будет соответствовать mail.google.com.
  • Шаблон хоста / URL – например, *.google.com.
  • Регулярное выражение (для хоста или полного URL).
  • Точный URL – полное совпадение.
  • Диапазон IP (CIDR) – например, 192.168.1.0/24.

Добавление правил

  • Из всплывающего окна: нажмите на домен в списке «Проксируемые ресурсы».
  • Вручную: на странице настроек в нужном профиле нажмите «Добавить правило».
  • Импорт: из файлов GFWList или SwitchyOmega.

Приоритет: правила белого списка всегда имеют более высокий приоритет и отключают прокси для указанных сайтов.

🖱 Контекстное меню

В таблице прокси (на странице настроек) нажмите правой кнопкой мыши на строке прокси. Появится меню, в котором можно:

  • Изменить рейтинг (+1, –1, сбросить)
  • Установить приоритет: 📌 закрепить или ⭐ добавить в избранное
  • Экспортировать выбранные прокси
  • Скопировать адреса выбранных прокси
  • Удалить выбранные прокси
  • Очистить статусы для выбранных или всех прокси
  • Запустить тесты для выбранных прокси (с выбором сайта)
  • Переместить выбранные прокси вверх/вниз (в таблице)

Во всплывающем окне (панель управления) при нажатии правой кнопкой мыши на активном прокси можно:

  • Изменить рейтинг
  • Установить приоритет
  • Добавить подписочный прокси в ручной список (если нажат прокси из подписки).

📤 Импорт / экспорт

Помимо базовых функций импорта/экспорта списка прокси, реализованы следующие улучшения:

  • Автоматическое переключение режима импорта: при вводе текста в поле ввода активируется режим «Текст списка прокси», при выборе файла — «Файл списка прокси».
  • Экспорт выбранных: в контекстном меню таблицы можно экспортировать только отмеченные серверы.

📋 Подписки на списки прокси и правил

Подписки на списки прокси

  • Вкладка «Подписки на прокси-серверы» → «Подписаться на список».
  • Укажите URL списка (форматы: PlainText, JSON, CSV).
  • Расширение будет автоматически обновлять список по расписанию (задаётся в минутах).
  • Прокси из подписок появляются в основном списке с пометкой источника.

Подписки на правила

  • Внутри профиля → «Подписки на правила» → «Подписаться на список правил».
  • Поддерживаются форматы AutoProxy/GFWList и SwitchyOmega.
  • Правила автоматически добавляются в профиль.

🔄 Синхронизация и резервное копирование

Синхронизация

  • Включите синхронизацию в общих настройках.
  • Выберите источник: синхронизация браузера или WebDAV-сервер.
  • Для WebDAV укажите URL, имя файла, логин и пароль.
  • Настройки синхронизируются автоматически при изменении.

Резервное копирование

  • Вкладка «Резервирование/восстановление».
  • Нажмите «Создать полную резервную копию» — будет скачан файл со всеми настройками, правилами и прокси.
  • Для восстановления выберите «Восстановить из резервной копии» и загрузите файл.

🎨 Темы оформления

  • В общих настройках выберите светлую, тёмную или автоматическую тему (следует за темой браузера).
  • Можно указать пользовательскую тему — вставьте URL CSS-файла (должен быть HTTPS).
  • Поддерживаются темы с bootswatch.com.

⌨️ Горячие клавиши

Вы можете настроить горячие клавиши в браузере (управление расширениями → горячие клавиши). Доступные команды:

  • Следующий / предыдущий прокси (циклическое переключение)
  • Переключение профилей: «Без прокси», «Выборочный», «Всегда включён», «Системный»

По умолчанию: Ctrl+Shift+1 — Прямое, Ctrl+Shift+2 — Выборочный, Ctrl+Shift+3 — Всегда, Ctrl+Shift+4 — Системный.

⚠️ Устранение неполадок

Расширение не работает в режиме инкогнито

В настройках браузера (управление расширениями) разрешите расширению работу в режиме инкогнито.

Точные и экспресс-тесты не работают в Firefox

Это связано с ограничениями API браузера. Используйте циклические тесты — они работают во всех браузерах.

Прокси не подключается

  • Проверьте правильность адреса и порта.
  • Убедитесь, что прокси-сервер запущен и доступен.
  • Если используется аутентификация, проверьте логин/пароль (Chrome не поддерживает аутентификацию для SOCKS).
  • Запустите тест для проверки доступности.

Статусы и рейтинг не отображаются

Включите опцию «Включить рейтинг для прокси» на вкладке «Прокси-серверы».

Не удаётся импортировать список прокси

Убедитесь, что список соответствует поддерживаемым форматам. Используйте автоматическое переключение режимов (текст/файл).

Ошибка при синхронизации через WebDAV

  • Проверьте URL и учётные данные.
  • Убедитесь, что файл доступен для записи.
  • Попробуйте выполнить ручное резервирование кнопкой «Резервировать сейчас».

Где посмотреть логи ошибок?

Откройте консоль разработчика (F12) на странице настроек или во всплывающем окне. Включите диагностику (кнопка «diag?» внизу страницы настроек) для детального логирования.
